你是数学讲义的结构编辑。下面是从同一节课的不同片段分别提取出的 {n} 个话题，存在重复、碎片化和同义反复。

【待归并的话题】
{topics_json}

任务：把它们归并成 **{lo}–{hi} 个章节级主题**，输出 JSON，不要输出任何其他内容：
{
  "chapters": [
    {
      "name": "章节级主题名（主题式命名，可带教材节号）",
      "summary": "一句话说明这一节讲了什么",
      "importance": "核心|重要|了解",
      "members": ["被归入本章的原话题名", "..."]
    }
  ]
}

归并规则：
1. **members 必须覆盖输入中的每一个话题，一个都不能遗漏**（原话题名照抄，不要改写）。
2. **同一讲授内容只能出现在一个章节里，严禁两章讲同一个对象**。例如"余子式与代数余子式的定义"与"行列式的定义与展开"若都讲余子式，必须合并成一章；"行列式的定义"与"行列式的归纳定义"是同一件事，必须合并。输出的各章范围不得互相重叠。
3. 同义/近义的合并为一条；上下位的归入上位主题；单个定义、单个定理、证明、推论、计算技巧、验证一律并入其所属主题。
4. 保持讲义的讲授顺序：先讲的章节排在前面。
5. 章节名用"主题式"命名，能看出这一节的范围，例如"行列式的定义与按列展开"。
6. importance 取该章内最高级别（核心 > 重要 > 了解）。
7. 只输出 JSON。
