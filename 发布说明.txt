# 数学笔记整理助手 · 发布说明
版本：Release v1.0.0    日期：2026-10-13

============================================================
一、这是什么
============================================================
一个完全本地运行的「数学课堂笔记整理助手」。把课程材料（飞书妙记
转写 txt、板书截图、老师发的 pdf/docx）放进一个文件夹，它会自动：

    读取 → 清洗口语废话 → 提取知识点话题 → 逐话题生成讲解 → 存成 Markdown 笔记

笔记风格：先直觉后严格、证明写全关键步骤、数学公式用纯文本+Unicode
符号（不使用 LaTeX）。生成时可联网补充参考资料（失败自动降级）。

【本地私有】AI 模型与数据都在本机，不联网也能跑，课堂内容不上传。

【本版本说明】这是**源码版**：仓库只含代码（约 0.06 MB），AI 模型
和 Ollama 运行时不打包，首次使用时由安装脚本**联网自动下载**。

============================================================
二、安装与启动（新设备第一次用）
============================================================
前提：装好 Python 3.10+（https://www.python.org/downloads/ ，
      安装时勾选 “Add Python to PATH”）。

【Windows】
  1. 双击「install.bat」 → 自动装依赖 + 下载模型（约 10GB，需联网，
     耐心等待）
  2. 装完后双击「启动.bat」
  3. 浏览器自动打开面板 http://127.0.0.1:14000/

【macOS / Linux】
  1. python3 install.py
  2. python3 launcher.py

> 若刚装好 Ollama 后脚本提示找不到，请关闭终端重新打开再运行
> （让 PATH 生效）。

============================================================
三、目录结构
============================================================
├─ install.py / install.bat   ← 一键安装（首次运行）
├─ launcher.py / 启动.bat     ← 一键启动（日常使用）
├─ README.md                  ← GitHub 项目说明
├─ 发布说明.txt               ← 本文件
└─ app/
    ├─ panel.py               操作面板（主入口）
    ├─ main.py                命令行入口
    ├─ config.py              全局配置
    ├─ requirements.txt       Python 依赖清单
    ├─ core/                  各功能模块
    ├─ prompts/               提示词模板
    ├─ projects/              【你的项目档案】
    └─ vault/                 【生成笔记的存放处】

============================================================
四、系统要求
============================================================
- 操作系统：Windows 10/11、macOS、Linux（64 位）
- Python 3.10+
- 内存：建议 16 GB 及以上
- 磁盘：模型约 10 GB（2 个模型）+ 依赖
- 显卡：有 NVIDIA 显卡（≥6GB 显存）最好，没有也能跑（慢）
- 安装时需联网；日常使用可离线（除“联网补充资料”功能）

============================================================
五、面板怎么用
============================================================
[项目管理] 标签页：先建一个项目，例如
    名称：高等代数
    背景：南开大学大一高等代数，教材丘维声
    要求：证明写全关键步骤，先直觉后严格，不用 LaTeX
  该项目的笔记会单独归档到 app/vault/项目_高等代数_日期/。

[整理] 标签页：
  1. 顶部下拉选项目（可选）
  2. 「输入文件夹路径」填要整理的文件夹（放 txt / jpg / pdf / docx）
  3. 点「① 判断」→ 自动清洗并列出知识点话题
  4. 可编辑话题后，点「② 生成并写入 vault」
  5. 右侧显示笔记预览和保存路径

============================================================
六、常见问题
============================================================
Q1. 启动时提示“依赖未装全 / 未安装 Ollama”？
    A. 先运行一次 install.bat（或 python3 install.py）。

Q2. Ollama 刚装好，脚本却提示找不到？
    A. 关闭终端/窗口重新打开（让 PATH 生效），再运行。

Q3. 模型下载慢或失败？
    A. ollama pull 需联网。可稍后手动执行：
       ollama pull qwen3:8b
       ollama pull qwen3-vl:8b

Q4. 生成很慢？
    A. 首次需加载模型（约几十秒），之后常驻内存会快。无独显会更慢。

Q5. 端口 14000 被占用？
    A. 说明面板已在运行，直接开 http://127.0.0.1:14000/ 即可。

Q6. 如何停止？
    A. 关闭“面板”窗口即可；Ollama 服务在后台常驻，重启电脑后停止。

============================================================
七、数据与隐私
============================================================
- 项目档案在 app/projects/，生成的笔记在 app/vault/。
- 除“联网补充资料”会访问搜索引擎外，其余处理全部本机完成，
  课堂原文不上传。

============================================================
八、技术组成
============================================================
- 界面：Gradio        推理：Ollama
- 模型：qwen3:8b（文本）、qwen3-vl:8b（图片 OCR）
- 运行：Python 3.10+ + requests / pdfplumber / python-docx
- 联网补充：必应搜索（可失败降级）

命令行进阶用法：
    cd app
    python main.py process "<输入文件夹>" --project <项目folder_name>
